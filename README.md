# GraphQL Standards Comparison for Associative Databases

This repository compares different implementations of GraphQL standards for associative database architectures:

- **Deep (PostgreSQL + Hasura)**: Traditional relational database with GraphQL layer
- **Doublets Rust**: High-performance native associative database
- **Doublets C#**: .NET-based associative database implementation

## What are GQL Standards?

See [GQL-STANDARDS.md](./GQL-STANDARDS.md) for comprehensive documentation on GraphQL standards for associative architecture.

## Performance Benchmarking

This project provides automated benchmarking tools to compare the performance and compatibility of different GraphQL server implementations that support the LinksStandard associative database schema.
